# NOVA AgentOS 1.1.0-preview.17

这个预览版重点收紧了长任务、多轮纠正、Agent Pack 和桌面执行体验。

## 本次更新

- 任务执行中收到用户纠正时，可中断当前可取消步骤，并沿用同一任务、上下文和工作区继续。
- 加强停止、恢复和迟到模型响应隔离，避免旧结果覆盖新方向。
- 改进 Agent Pack 导入、旧格式迁移、编译和运行前校验。
- 优化工作区写入权限、终端授权、MCP 生命周期和浏览器任务处理。
- 简化 Windows 与 macOS 桌面界面，提升任务状态、交付物和执行过程的可读性。
- 更新中英文 README、A2A 与插件式自进化技术资料。

## Windows 包

`NOVA-AgentOS-Electron-1.1.0-preview.17-x64.zip`

解压后运行 NOVA AgentOS。首次启动时请选择可写工作区并连接模型。

## 验证

- Electron/Vite 生产构建通过。
- AgentOS Bridge 发布通过。
- 上下文胶囊烟雾测试通过。
- Electron 主进程语法检查通过。

## English summary

Preview 17 improves interruptible in-flight guidance, safe task recovery, Agent Pack compatibility, workspace and shell permissions, MCP/browser lifecycle handling, and desktop UI clarity across Windows and macOS.
