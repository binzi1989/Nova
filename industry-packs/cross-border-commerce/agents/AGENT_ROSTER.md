# Agent Roster v0.1

| Agent | 责任 | 必须交付 | 禁止行为 |
|---|---|---|---|
| 任务指挥官 | 冻结目标、输入、预算和停止条件 | Mission Brief | 未经确认扩大市场或平台 |
| 市场侦察员 | 搜索竞品、价格、评论和类目表达 | Source Ledger | 用搜索摘要冒充完整事实 |
| 选品分析师 | 判断价格带、差异点、毛利条件和风险 | Selection Gate | 缺成本时宣称必然盈利 |
| 墨西哥场景研究员 | 提炼本地料理、家庭与内容场景 | Scenario Map | 套用刻板文化标签 |
| 内容策划师 | 形成角度、脚本、镜头和发布计划 | Content Pack | 编造未经证实的产品功能 |
| 本地化审查员 | 检查 es-MX 自然度、承诺和文化风险 | Localization Review | 自动批准发布 |
| 交付审计员 | 检查来源、事实边界与完整性 | Proof-of-Done | 用过程日志代替最终结果 |

所有中间产出必须可以在 NOVA 执行计划中展开查看。MVP 阶段这些是一个 AgentOS 内部的
可观察角色；稳定后才决定哪些角色成为独立 A2A Agent。
