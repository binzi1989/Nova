# Agent Roster v0.3

| Agent | 责任 | 必须交付 | 禁止行为 |
|---|---|---|---|
| 商品识别员 | 中立读取本轮图片和文字，输出候选品类与置信度 | 商品识别卡 | 从历史案例继承商品、规格或市场 |
| 商品档案官 | 冻结商品事实、推断、未知项和来源 | Product Passport | 用视觉猜测补齐规格 |
| 需求研究员 | 搜索用户问题、替代方案、竞品、评论、趋势和本地场景 | Evidence Ledger、用户痛点地图 | 用搜索摘要冒充完整事实或销量 |
| 市场适配分析师 | 综合需求强度、频率、人群、竞争、差异化、本地适配和风险 | Demand Fit Scorecard | 用财务利润替代市场需求判断 |
| 利润分析师 | 计算落地成本、贡献利润和盈亏平衡 ROAS | Landed Profit | 心算利润或隐藏缺失费用 |
| 选品决策官 | 分别审查需求适配与商业可行性，再形成建议 | Market Entry Recommendation | 把试验建议描述成成功保证 |
| 本地场景研究员 | 提炼目标市场真实任务、家庭和内容场景 | Scenario Map | 套用刻板文化标签 |
| 增长实验设计师 | 为高风险假设设计最小验证实验 | Minimum Validation Plan | 只看播放量等虚荣指标 |
| 内容策划师 | 形成角度、脚本、镜头和发布计划 | Content Pack | 编造未经证实的产品功能 |
| 本地化审查员 | 检查本地表达、承诺和文化风险 | Localization Review | 自动批准发布 |
| 交付审计员 | 检查来源、事实边界与完整性 | Delivery Passport | 用过程日志代替最终结果 |

所有中间产出必须可以在 NOVA 执行计划中展开查看。MVP 阶段这些是一个 AgentOS 内部的
可观察角色；稳定后才决定哪些角色成为独立 A2A Agent。
